# Complejidad Computacional

## Conceptos clave


- **Tiempo Practico:** el tiempo teorico es el tiempo promedio o estimado que le llevaria a una computadora ejecutar y terminar una tarea 

- **Tiempo Teorico:** es simplemente el tiempo teorico o lo que se supone que se debe tardar en terminar la ejecucion de un programa, este tipo de tiempo no se mide en segundos. Es medida es unidad de tiempo 

  - asignacion=`int x=2` dura una unidad de tiempo
  -comparacion= `if(x>2)` dura 1 unidad de tiempo pero solo la comparacion

  - la duracion de un bloque se obtiene sumando las duraciones de las instrucciones que contenga

  *hay que tomar en cuenta que el tiempo teorico y el practico siempre va a variar dependiendo del caso*
